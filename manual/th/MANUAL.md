## 1. Cleona Chat คืออะไร?

### แอปส่งข้อความของคุณ ข้อมูลของคุณ

Cleona Chat เป็นแอปส่งข้อความที่ทำงานได้โดยไม่ต้องมีเซิร์ฟเวอร์กลางเลย
ข้อความของคุณเดินทางจากอุปกรณ์ของคุณไปยังอุปกรณ์ของคู่สนทนา --
โดยไม่ต้องผ่านสำนักงานบริษัท ไม่ต้องผ่านคลาวด์ ไม่ต้องผ่านศูนย์ข้อมูล
หากระหว่างทางมีอุปกรณ์อื่นช่วยเหลือ มันก็แค่ส่งต่อแพ็กเกจที่เข้ารหัสไปข้างหน้า
ไม่มีบริษัทใดสามารถอ่าน จัดเก็บ หรือส่งต่อข้อความของคุณได้
เพราะแทบไม่มีบริษัทใดคอยอยู่ตรงกลางเลย

### ไม่ต้องมีบัญชี ไม่ต้องมีหมายเลขโทรศัพท์

ใน Cleona คุณไม่ต้องมีหมายเลขโทรศัพท์หรือที่อยู่อีเมลเพื่อสมัครใช้งาน
ตัวตนของคุณประกอบด้วยคู่กุญแจเข้ารหัสที่ถูกสร้างขึ้นโดยอัตโนมัติบนอุปกรณ์ของคุณ
เมื่อเริ่มใช้งานครั้งแรก นั่นหมายความว่า ไม่มีใครตามหาคุณได้ผ่านหมายเลขโทรศัพท์
หรือที่อยู่อีเมล เว้นแต่คุณจะแจ้งข้อมูลติดต่อของคุณเอง

### การเข้ารหัสที่รองรับอนาคต

Cleona ใช้การเข้ารหัสแบบที่เรียกว่า Post-Quantum นั่นหมายความว่า
แม้แต่คอมพิวเตอร์ควอนตัมในอนาคตก็ไม่สามารถแกะข้อความของคุณได้
คุณไม่จำเป็นต้องเข้าใจรายละเอียดทั้งหมด -- สำคัญแค่ว่าการสื่อสารของคุณได้รับการปกป้อง
ให้ดีที่สุดเท่าที่เทคโนโลยีปัจจุบันเป็นไปได้

### มันทำงานได้อย่างไรโดยไม่มีเซิร์ฟเวอร์?

เครือข่ายของ Cleona ประกอบด้วยอุปกรณ์ของผู้ใช้เท่านั้น อุปกรณ์ทุกเครื่องคือโหนดหนึ่ง
ไม่มีโหนดใดสำคัญไปกว่าโหนดอื่น และแต่ละโหนดรู้จักแค่เพื่อนบ้านของตัวเอง
มีสี่อย่างที่ทำให้เครือข่ายนี้พิเศษ:

- **ไม่มีจุดยึดติดถาวร.** ในแอปไม่มีที่อยู่เซิร์ฟเวอร์ และเครือข่ายไม่พึ่งพา
  โหนดใดโหนดเดียว ไม่มีอะไรที่ใครจะปิดได้เพื่อปิด Cleona
- **ทันทีทันใด.** ข้อความของคุณออกตัวในขณะที่คุณส่งมัน มันไม่รอ
  จังหวะใดและไม่รอสิ่งอื่นใด
- **การพรางไปด้วยข้างกาย.** อุปกรณ์ของคุณส่งแพ็กเกจพรางขนาดเล็กอยู่ตลอดเวลา
  เพื่อให้มองจากภายนอกไม่รู้ว่าคุณกำลังเขียนจริงเมื่อไหร่ ไม่มีข้อความใด
  ขึ้นอยู่กับมัน -- การพรางทำงานอยู่ข้างกายเท่านั้น
- **รหัสแทนชื่อ.** ใครก็ตามที่ส่งต่อข้อความจะเห็นแค่รหัสที่เปลี่ยนไปทุกวัน
  โดยปกติไม่มีใครในหมู่พวกเขารู้ทั้งผู้ส่งและผู้รับในเวลาเดียวกัน
  ข้อยกเว้นอยู่ในบทที่ 14

**สามเส้นทาง พร้อมกันทั้งหมด.** เมื่อคุณส่งข้อความ Cleona ไม่ได้ลองทีละเส้นทาง
แต่ลองทุกเส้นทางที่เหมาะสมพร้อมกันเลย ทันทีที่คู่สนทนายืนยันการรับ
เส้นทางอื่นก็ถูกยกเลิก

1. **ในเครือข่ายเดียวกัน:** หากคุณอยู่ใน Wi-Fi เดียวกัน ข้อความจะ
   ข้ามไปโดยตรง
2. **ผ่านเพื่อนบ้านถาวร:** บนอินเทอร์เน็ต อุปกรณ์ของคุณส่งข้อความ
   ให้เพื่อนบ้านถาวรของมัน ตัวนั้นส่งต่อไปยังเพื่อนบ้านถาวร
   ของคู่สนทนาของคุณ (สูงสุดสามตัวพร้อมกัน) และตัวใดตัวหนึ่งส่งมอบ
3. **กล่องจดหมาย:** หากคู่สนทนาของคุณออฟไลน์ Cleona ฝากข้อความ
   ที่เข้ารหัสไว้ที่เพื่อนบ้านสามตัว มันจะอยู่ที่นั่นสูงสุด 7 วัน
   เมื่อคู่สนทนาของคุณออนไลน์อีกครั้ง เขาก็ไปเอามัน

**คุณเข้าสู่เครือข่ายได้อย่างไร?** ในแอปไม่มีที่อยู่เซิร์ฟเวอร์
คุณได้จุดเข้าจากผู้ติดต่อคนแรกของคุณ: คำเชิญของเขามีที่อยู่
ที่อุปกรณ์ของคุณใช้ค้นหาเพื่อนบ้านกลุ่มแรก ใน Wi-Fi เดียวกัน
อุปกรณ์ Cleona ก็หากันเองได้ จากนั้นอุปกรณ์ของคุณจะรู้จักเพื่อนบ้านเพิ่มขึ้น
จากทุกเพื่อนบ้านที่มันพบ

### แพลตฟอร์ม

Cleona มีให้ใช้งานสำหรับ Android, iOS, macOS, Linux และ Windows
บนคอมพิวเตอร์และบน Android
ข้อความและการโทรมาถึงภายในไม่กี่วินาที บน iPhone
ข้อนี้ใช้ได้ตราบเท่าที่แอปเปิดอยู่ เมื่อแอปไม่ได้เปิดอยู่ iOS
จะปลุกแอปเป็นครั้งคราวเพียงชั่วขณะ ว่าจะปลุกเมื่อไรนั้น iOS
เป็นผู้กำหนด จากนั้น Cleona จะรับทุกสิ่งที่เก็บไว้ให้คุณ
และแสดงการแจ้งเตือนพร้อมตัวเลขบนไอคอนแอป การโทรจะไปไม่ถึง iPhone
ที่แอปไม่ได้เปิดอยู่ นี่คือกฎของ Apple ไม่ใช่ความผิดพลาดของ
Cleona

## 2. เริ่มต้นใช้งาน

### ติดตั้งแอป

**Android:**
1. ดาวน์โหลดไฟล์ APK จากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. เปิดไฟล์บนโทรศัพท์ของคุณ หากจำเป็น อนุญาตการติดตั้ง
   จากแหล่งที่ไม่รู้จัก (Android จะถามคุณโดยอัตโนมัติ)
3. แตะ "ติดตั้ง" และรอจนการติดตั้งเสร็จสมบูรณ์

**iOS:**
1. เปิดลิงก์คำเชิญ TestFlight บน iPhone ของคุณ
2. แตะ "ติดตั้ง" TestFlight คือวิธีทางการของ Apple
   ในการแจกจ่ายแอปเบต้า
3. หลังติดตั้งเสร็จ คุณจะพบ Cleona บนหน้าจอหลักของคุณ

**macOS:**
1. ดาวน์โหลดไฟล์ DMG จากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. เปิด DMG แล้วลาก Cleona ไปยังโฟลเดอร์ Applications ของคุณ
3. ในการเปิดครั้งแรก macOS อาจถามว่าคุณต้องการเปิดแอปจาก
   นักพัฒนาที่ได้รับการระบุหรือไม่ -- ยืนยันสิ่งนี้

**Linux (Ubuntu/Debian):**
1. ดาวน์โหลดไฟล์ .deb จากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. ติดตั้งด้วยดับเบิลคลิกหรือในเทอร์มินัล: `sudo dpkg -i cleona-chat-beta_VERSION_amd64.deb`
3. เปิด Cleona จากเมนูแอปพลิเคชันหรือในเทอร์มินัลด้วย `cleona-chat-beta`

**Linux (Fedora/openSUSE):**
1. ดาวน์โหลดไฟล์ .rpm จากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. ติดตั้งด้วย: `sudo dnf install cleona-chat-beta-VERSION-1.x86_64.rpm`
3. เปิด Cleona จากเมนูแอปพลิเคชันหรือในเทอร์มินัลด้วย `cleona-chat-beta`

**Linux (ทุกดิสตริบิวชัน -- AppImage):**
1. ดาวน์โหลดไฟล์ .AppImage จากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. ตั้งไฟล์ให้เป็นไฟล์ปฏิบัติการ: คลิกขวา, คุณสมบัติ, ปฏิบัติการ หรือใน
   เทอร์มินัล: `chmod +x cleona-chat-beta-VERSION-x86_64.AppImage`
3. เปิดด้วยดับเบิลคลิกหรือในเทอร์มินัล: `./cleona-chat-beta-VERSION-x86_64.AppImage`

ชื่อแพ็กเกจใช้กับเบต้า ซึ่งตอนนี้เป็นฉบับเดียวที่เผยแพร่
ชื่อคือ `cleona-chat-beta`

**Windows:**
1. ดาวน์โหลดตัวติดตั้งจากเว็บไซต์ Cleona หรือจาก GitHub Releases
2. เรียกใช้ไฟล์ติดตั้งและทำตามคำแนะนำ
3. เปิด Cleona จากเมนู Start หรือทางลัดบนเดสก์ท็อป

### สร้างตัวตน

ในการเปิดครั้งแรก Cleona สร้างตัวตนใหม่ให้คุณโดยอัตโนมัติ
คุณสามารถตั้งชื่อที่แสดงให้ตัวเอง -- นั่นคือชื่อที่ผู้ติดต่อของคุณเห็น
ชื่อนี้เปลี่ยนได้ตลอดเวลา

### จดวลีรหัสฟื้น -- สำคัญที่สุดเลย

หลังสร้างตัวตน Cleona จะแสดง 24 คำให้คุณ นั่นคือ
**วลีรหัสฟื้น** ของคุณ -- กุญแจกู้คืนส่วนตัวของคุณ

**จด 24 คำนี้ลงบนกระดาษและเก็บรักษาไว้ให้ปลอดภัย**

ทำไมมันถึงสำคัญมาก?

- หากโทรศัพท์ของคุณพัง หาย หรือถูกขโมย คุณสามารถกู้คืนตัวตน
  ทั้งหมดของคุณบนอุปกรณ์ใหม่ด้วย 24 คำนี้
- หากไม่มีวลีรหัสฟื้น ก็ไม่มีทางกลับ ไม่มีปุ่ม "ลืมรหัสผ่าน"
  และไม่มีฝ่ายสนับสนุนที่จะคืนบัญชีให้คุณได้ -- เพราะ
  ไม่มีบัญชีอยู่บนเซิร์ฟเวอร์เลย แม้แต่ผู้ติดต่อของคุณก็
  กู้คืนตัวตนของคุณไม่ได้ ไม่ว่าจะมีกี่คนก็ตาม อุปกรณ์ที่สอง
  ที่มีตัวตนเดียวกันจะมากับเวอร์ชันถัดไป (ดูบทที่ 11)
- อย่ามอบวลีรหัสฟื้นให้ผู้อื่นเด็ดขาด ใครก็ตามที่รู้คำเหล่านี้
  สามารถแอบอ้างเป็นคุณได้

คุณหา 24 คำได้ภายหลังในการตั้งค่าภายใต้ "สำรองข้อมูล" ->
"แสดงวลีกู้คืน" หากต้องการอ่านมันอีกครั้ง บน Android คุณ
ยืนยันด้วยการล็อกหน้าจอของคุณสำหรับสิ่งนี้

### เพิ่มผู้ติดต่อคนแรก

เพื่อแชทกับใคร คุณต้องเพิ่มคนนั้นเป็นผู้ติดต่อก่อน
มีหลายวิธีที่จะทำเช่นนี้ -- ทั้งหมดถูกอธิบายไว้ใน
ส่วนถัดไป

## 3. รายชื่อผู้ติดต่อ

### คำเชิญของคุณ

ผู้ติดต่อใน Cleona เกิดขึ้นได้ผ่านคำเชิญเท่านั้น คำเชิญของคุณ
อยู่ที่นั่นตั้งแต่เริ่มใช้งานครั้งแรก -- แม้ไม่มีอินเทอร์เน็ตและ
ก่อนที่อุปกรณ์ของคุณจะพบเพื่อนบ้านเลย คุณหามันได้บนหน้า
รายละเอียดตัวตนของคุณ (แตะชื่อของตัวเองในแถบบนสุด)

คำเชิญมีสองรูปแบบที่บรรจุสิ่งเดียวกันทุกประการ:

- เป็น **QR code** เมื่อคู่สนทนาของคุณยืนอยู่ข้างๆ คุณ และ
- เป็น **บรรทัดข้อความ** ที่คุณส่งผ่านอีเมล SMS หรือผ่านแอป
  ส่งข้อความอื่น

คำเชิญไม่มีหมายเลขโทรศัพท์และไม่มีชื่อจากสมุดโทรศัพท์ใดๆ มันมี
กุญแจสาธารณะของคุณและที่อยู่ที่คู่สนทนาของคุณใช้ติดต่อ
คุณและเพื่อนบ้านของคุณ สำหรับคนที่เพิ่งติดตั้ง Cleona
คำเชิญของคุณจึงเป็นจุดเข้าสู่เครือข่ายด้วย

### สแกน QR code (แนะนำ)

เมื่อคุณพบกันตัวต่อตัว:

1. คุณแสดง QR code ของคำเชิญของคุณให้คู่สนทนาเห็น
2. คู่สนทนาของคุณแตะปุ่มบวก เลือก "สแกน QR code" และ
   เล็งกล้องไปที่หน้าจอของคุณ นี่ใช้ได้กับเว็บแคมของ
   คอมพิวเตอร์ด้วย
3. คำขอไปหาคุณและถูก **รับโดยอัตโนมัติ** -- เพราะ
   คุณเพิ่งแสดงรหัสเอง

QR code ใช้ได้ครั้งเดียว: คำขอที่ถูกต้องแรกถูกรับ
หลังจากนั้นคำเชิญก็ถูกใช้จนหมด QR code เป็นวิธีที่ปลอดภัยที่สุด
เพราะขณะทำคุณรู้แน่ชัดว่าคุณกำลังแลกผู้ติดต่อกับใคร

### NFC (นำโทรศัพท์มาแนบกัน)

เมื่อทั้งสองอุปกรณ์รองรับ NFC:

1. เปิดฟังก์ชันเพิ่มผู้ติดต่อบนทั้งสองเครื่อง
2. นำโทรศัพท์ของคุณมาแนบหลังติดหลังกัน
3. คำเชิญถูกส่งผ่านและรับโดยอัตโนมัติ

NFC เหมือน QR code ให้ความปลอดภัยระดับสูง เพราะการแลก
จะทำได้ก็ต่อเมื่อคุณยืนอยู่ใกล้กันทางกายภาพ

### ส่งบรรทัดข้อความ

เมื่อคุณไม่สามารถพบกันได้:

1. เปิดคำเชิญของคุณและคัดลอกบรรทัดข้อความ
2. ส่งมันให้คนที่ควรจะเพิ่มคุณ -- ทางอีเมล SMS หรือ
   ผ่านแอปส่งข้อความอื่น
3. อีกฝ่ายวางบรรทัดนั้นใน Cleona ในกล่องโต้ตอบเพิ่มผู้ติดต่อ
4. คำขอปรากฏทางฝั่งคุณใต้ **"คำขอ"** ที่นี่ **ไม่**ได้
   รับโดยอัตโนมัติ: คุณตัดสินใจเอง เพราะคุณไม่รู้
   ว่าใครอ่านบรรทัดนั้นระหว่างทางอีกบ้าง

### รับคำขอผู้ติดต่อ

คำขอที่เข้ามายังไม่ได้สร้างผู้ติดต่อ มันเป็นคำถามหนึ่งต่อคุณ
และปรากฏในแท็บ **"คำขอ"** ที่นั่นคุณเห็นชื่อและ
ระดับการยืนยันและสามารถเลือก:

- **รับ** -- เฉพาะตอนนี้คนนั้นจึงกลายเป็นผู้ติดต่อของคุณ
- **ปฏิเสธ** -- คำขอถูกทิ้งไป
- **บล็อก** -- คนนั้นส่งคำขอเพิ่มให้คุณไม่ได้อีก

### ห้ามใช้เป็นเพื่อนบ้านถาวร

ในเมนูของผู้ติดต่อคุณพบสวิตช์ **"ห้ามใช้เป็นเพื่อนบ้านถาวร"**
(ค่าตั้งต้น: ปิด) เมื่อเปิด ผู้ติดต่อนี้ไม่ส่งต่อข้อความ
ให้คุณและจึงไม่รู้ด้วยว่าคุณส่งหรือรับข้อความเมื่อไหร่
นี่มีไว้สำหรับกรณีที่อันตรายมาจากคนรอบข้างตัวคุณเอง

จากคนแปลกหน้า (ไม่ใช่ทั้งผู้ติดต่อและไม่ใช่สมาชิกของกลุ่มร่วม)
Cleona ไม่ยอมให้อะไรผ่านนอกจากคำขอเช่นนั้น --
ไม่มีข้อความ ไม่มีการโทร ไม่มีไฟล์ และแม้แต่คำขอก็มาถึงได้
ก็ต่อเมื่อผู้ส่งแก้ภารกิจคำนวณเล็กๆ ก่อนหน้านั้น นั่นทำให้
สแปมจำนวนมากมีต้นทุนสูง

### ระดับการยืนยัน

Cleona แสดงให้คุณเห็นว่าตัวตนของผู้ติดต่อได้รับการยืนยัน
ปลอดภัยเพียงใด:

| ระดับ | ความหมาย |
|-------|-----------|
| ยังไม่ยืนยัน | คุณเชื่อมต่อกันแล้ว แต่ไม่มีอะไรยืนยันว่าเป็นคนที่ถูกต้องจริงๆ อยู่เบื้องหลัง |
| เห็นแล้ว | การแลกกุญแจสำเร็จ คุณสามารถสื่อสารกันแบบเข้ารหัสได้ |
| ยืนยันแล้ว | คุณพบกันตัวต่อตัวและเชื่อมต่อผ่านการสแกนกล้องหรือ NFC |
| ไว้วางใจ | คุณได้ทำเครื่องหมายผู้ติดต่อนี้อย่างชัดแจ้งว่าน่าเชื่อถือ |

"ยืนยันแล้ว" มีเฉพาะการแลกตัวต่อตัว คำเชิญที่มาผ่าน
แชทหรือทางอีเมลจะไม่มาถึงระดับนี้ -- แม้จะมีข้อมูลเดียวกัน

หากกุญแจของผู้ติดต่อเปลี่ยนโดยไม่แจ้งล่วงหน้า Cleona จะ
รีเซ็ตเขาเป็น "ยังไม่ยืนยัน" นั่นปกป้องคุณจากการที่ใคร
แอบอ้างเป็นผู้ติดต่อของคุณโดยไม่รู้ตัว

## 4. ข้อความ

### ส่งและรับข้อความ

เพียงพิมพ์ข้อความของคุณลงในช่องป้อนข้อมูลด้านล่างแล้วกด Enter หรือ
ปุ่มส่ง ข้อความของคุณถูกเข้ารหัสโดยอัตโนมัติก่อนออกจาก
อุปกรณ์ของคุณ

ข้อความที่เข้ามาปรากฏในประวัติแชท

### เครื่องหมายที่ข้อความของคุณหมายถึงอะไร

| เครื่องหมาย | ความหมาย |
|---------|-----------|
| นาฬิกา | ข้อความถูกสร้างขึ้นแล้ว แต่ยังไม่มีเส้นทางใดพามันไป |
| ติ๊กเดียว | ข้อความกำลังเดินทาง นี่รวมถึงขณะที่มันรออยู่ในกล่องจดหมายรอคู่สนทนาของคุณด้วย |
| ติ๊กคู่ | ส่งมอบแล้ว: อุปกรณ์ของคู่สนทนายืนยันการรับแล้ว |
| เครื่องหมายเตือน | 14 วันที่ไม่มีเส้นทางใดส่งข้อความถึง แตะมันเพื่อส่งใหม่ |

**ออฟไลน์ไม่ใช่ข้อผิดพลาด.** หากคู่สนทนาของคุณไม่สามารถติดต่อได้
ข้อความจะค้างที่ติ๊กเดียวจนกว่าจะถูกเอาไป -- มันไม่ได้หายไป
หากอุปกรณ์ของคุณเองไม่มีการเชื่อมต่อ ข้อความจะค้างอยู่ที่นาฬิกา
และออกเดินทางเองทันทีที่มีเส้นทางอีกครั้ง เครื่องหมายเตือนปรากฏ
ก็ต่อเมื่อมันหาเส้นทางไม่ได้ตลอด 14 วัน; จากนั้นคุณส่งใหม่ได้

ข้อนี้ใช้กับ iPhone ที่แอปไม่ได้เปิดอยู่เช่นกัน:
ข้อความจะรออยู่ในกล่องจดหมายจนกว่า iOS จะปลุกแอปเป็นชั่วขณะ
หรือจนกว่าอีกฝ่ายจะเปิดแอป ซึ่งอาจใช้เวลานานกว่าบนอุปกรณ์อื่น

ติ๊กคู่มีก็ต่อเมื่อผู้รับยืนยันการรับด้วยตัวเอง ใบยืนยันนี้
ถูกเข้ารหัสและลงลายมือชื่อ -- ไม่มีใครระหว่างทาง
ปลอมมันได้เพื่อหลอกคุณว่าส่งมอบแล้ว

### ส่งภาพ วิดีโอ และไฟล์

คุณมีหลายทางเลือก:

- **ไอคอนคลิปหนีบกระดาษ** ในช่องป้อนข้อมูล: แตะมันเพื่อเลือกไฟล์ ภาพ
  หรือวิดีโอจากแกลเลอรีหรือระบบไฟล์ของคุณ
- **ลากแล้ววาง** (เดสก์ท็อป): ลากไฟล์ไปในหน้าต่างแชท
- **วางจากคลิปบอร์ด** (เดสก์ท็อป): คัดลอกภาพแล้ววางใน
  แชท

ไฟล์เล็ก (ต่ำกว่า 256 KB) เดินทางไปกับข้อความโดยตรง ไฟล์
ใหญ่กว่าจะถูกแบ่งเป็นชิ้นและใส่การแก้ไขความผิดพลาด เพื่อให้
ชิ้นที่หายไปบางส่วนไม่เป็นไร หากคุณทั้งคู่ออนไลน์
มันจะถูกสตรีมผ่านเพื่อนบ้าน; มิฉะนั้นมันจะถูกฝากไว้ที่อุปกรณ์
ที่เข้าถึงได้ตลอดเวลา จนกว่าคู่สนทนาของคุณจะเอาไป

ตั้งแต่ 256 KB Cleona ถามคุณทีละไฟล์ก่อนส่ง: ไฟล์ขนาดใหญ่
ไม่สามารถเดินทางบนเส้นทางข้อความของคุณได้ เนื้อหาของมัน
ยังเข้ารหัสอยู่ และคู่สนทนาของคุณไม่รู้ที่อยู่อินเทอร์เน็ตของคุณ
แต่การถ่ายโอนมองจากภายนอกเห็นเป็นเหตุการณ์ และอุปกรณ์
ของผู้อื่นที่ส่งต่อหรือเก็บรักษามัน เห็นว่าใครอัปโหลดและใคร
เอาไป ความยินยอมของคุณใช้เฉพาะไฟล์นี้ไฟล์เดียว

### ข้อความเสียง

1. กดค้างปุ่มไมโครโฟนในช่องป้อนข้อมูล
2. พูดข้อความของคุณ
3. ปล่อยปุ่มเพื่อส่งข้อความ

หากการรู้จำเสียงเปิดอยู่บนอุปกรณ์ของคุณ (ดูการตั้งค่า)
ข้อความเสียงของคุณจะถูกถอดเป็นข้อความโดยอัตโนมัติ คู่สนทนาของคุณ
จะเห็นทั้งการบันทึกและข้อความที่ถอดแล้ว

### ตอบข้อความ (อ้างอิง)

เพื่อตอบข้อความใดข้อความหนึ่งโดยเฉพาะ:

1. เปิดเมนูสามจุดข้างข้อความ
2. เลือก "ตอบ"
3. แบนเนอร์พร้อมข้อความที่อ้างอิงปรากฏเหนือช่องป้อนข้อมูล
4. เขียนคำตอบของคุณและส่ง

ข้อความที่อ้างอิงจะแสดงในคำตอบของคุณ เพื่อให้ความเกี่ยวข้อง
ชัดเจน

### แก้ไขและลบข้อความ

- **แก้ไข:** เมนูสามจุดของข้อความ แล้ว "แก้ไข"
  เปลี่ยนข้อความแล้วส่งใหม่ คู่สนทนาของคุณเห็นว่าข้อความ
  ถูกแก้ไขแล้ว การแก้ไขทำได้ภายใน 15 นาทีหลังส่ง
- **ลบ:** เมนูสามจุดของข้อความ แล้ว "ลบ" ข้อความ
  ถูกลบจากฝั่งคุณและฝั่งคู่สนทนาของคุณ คุณสามารถลบ
  ข้อความของตัวเองได้ตลอดเวลา -- ไม่มีช่วงเวลาจำกัดสำหรับ
  การลบ

### ปฏิกิริยาด้วยอิโมจิ

แทนที่จะเขียนคำตอบ คุณสามารถตอบข้อความด้วยอิโมจิ:

1. เปิดเมนูสามจุดหรือกดค้างข้อความ
2. เลือกอิโมจิจากตัวเลือกด่วน หรือเปิดตัวเลือกอิโมจิ
   เพื่อเลือกทั้งหมด
3. ปฏิกิริยาของคุณปรากฏใต้ข้อความ

### คัดลอกข้อความ

ผ่านเมนูสามจุดของข้อความ คุณสามารถคัดลอกข้อความไป
ยังคลิปบอร์ด

### ค้นหาข้อความ

ที่ด้านบนของหน้าต่างแชทคุณพบฟังก์ชันค้นหา ป้อน
คำค้น และ Cleona แสดงผลลัพธ์ทั้งหมดในแชทปัจจุบัน ด้วย
ปุ่มลูกศรคุณสามารถกระโดดไปมาระหว่างผลลัพธ์

บนหน้าเริ่มต้นมีตัวกรองค้นหาข้ามแท็บเพิ่มเติม ที่
คุณใช้ค้นทุกบทสนทนาตามคำหนึ่งได้

### ตัวอย่างลิงก์

เมื่อคุณส่งลิงก์ Cleona สร้างตัวอย่างโดยอัตโนมัติ (ชื่อ
คำอธิบาย ภาพตัวอย่าง) ตัวอย่างนี้ถูกสร้างโดยอุปกรณ์ของคุณ
และส่งไปด้วย -- คู่สนทนาของคุณไม่ต้องสร้างการเชื่อมต่อ
ไปยังเว็บไซต์ที่ลิงก์ชี้เพื่อมัน

สิ่งที่การแตะลิงก์ที่รับทำ คุณตั้งได้ในการตั้งค่าภายใต้
"การเปิดลิงก์": "ปกติ", "เลือกใช้หน้าต่างส่วนตัว" (ที่อุปกรณ์
เปิดหน้าต่างส่วนตัวไม่ได้ ลิงก์จะเปิดแบบปกติ) หรือ "ถามทุกครั้ง"

## 5. กลุ่ม

### สร้างกลุ่ม

1. สลับไปแท็บ "กลุ่ม"
2. แตะปุ่มบวก
3. ตั้งชื่อให้กลุ่ม
4. เลือกผู้ติดต่อที่คุณต้องการเชิญ
5. แตะ "สร้าง"

ผู้ติดต่อที่ถูกเชิญจะได้รับการแจ้งเตือนและสามารถเข้าร่วมกลุ่ม

### ข้อความกลุ่มได้รับการปกป้องอย่างไร

ในกลุ่มที่มีสมาชิกสูงสุด 16 คน Cleona ส่งข้อความแต่ละรายการ
ให้แต่ละสมาชิกทีละคน -- เข้ารหัสเฉพาะสำหรับสมาชิกนั้น เหมือนกับ
ว่าคุณเขียนข้อความแยกให้แต่ละคน ติ๊กบนข้อความกลุ่มแสดงสถานะ
ของสมาชิกที่คืบหน้าน้อยที่สุด

เมื่อกลุ่มโตเกิน 16 สมาชิก กลุ่มจะใช้กุญแจร่วมกันหนึ่งอัน
มันเปลี่ยนทุกวันและถูกสร้างใหม่เมื่อสมาชิกออกหรือถูกลบ;
สมาชิกใหม่อ่านได้เฉพาะตั้งแต่เข้าร่วม ที่นั่นติ๊กไม่ได้แสดง
สถานะของสมาชิกทุกคนอีกต่อไป แต่แสดงว่าข้อความถูกฝากไว้
ในเครือข่ายแล้ว เมื่อกลุ่มลดลงเหลือ 12 สมาชิกหรือน้อยกว่า
กลุ่มจะกลับไปส่งแบบรายบุคคล

### รูปภาพในกลุ่มและช่อง

ในการตั้งค่าของกลุ่มหรือช่อง คุณกำหนดด้วย "โหลดรูปภาพเสมอ"
ว่ารูปภาพจะถูกโหลดทันที หรือเมื่อคุณแตะรูปหนึ่งๆ เท่านั้น

### เชิญสมาชิก

แม้หลังสร้างแล้ว คุณสามารถเชิญผู้ติดต่อเพิ่มเติม:

1. เปิดข้อมูลกลุ่ม (เมนูสามจุดในภาพรวมกลุ่มหรือ
   แถบบนในแชทกลุ่ม)
2. แตะ "เชิญ"
3. เลือกผู้ติดต่อที่คุณต้องการเพิ่ม

### บทบาท

กลุ่มทุกกลุ่มมีสามบทบาท:

- **เจ้าของ (Owner):** มีการควบคุมเต็ม สามารถเพิ่มและลบสมาชิก
  แต่งตั้งแอดมิน และจัดการกลุ่ม เจ้าของสามารถโอนสถานะ
  ของตนให้สมาชิกคนอื่นด้วย
- **แอดมิน:** สามารถลบสมาชิกและช่วยจัดการ
- **สมาชิก:** สามารถอ่านและเขียนข้อความ

### ออกจากกลุ่ม

1. เปิดเมนูสามจุดในภาพรวมกลุ่ม
2. เลือก "ออก"
3. ยืนยันการตัดสินใจของคุณ

เมื่อคุณออกจากกลุ่ม ข้อความก่อนหน้าของคุณยังคง
มองเห็นได้สำหรับสมาชิกคนอื่น

## 6. ช่องสาธารณะ

### ช่องคืออะไร?

ช่องคือกระดานสนทนาสาธารณะภายในเครือข่าย Cleona
ตรงข้ามกับกลุ่ม ที่นี่ใครก็ตามสามารถอ่านได้โดยไม่ต้อง
ถูกเชิญ เฉพาะเจ้าของและแอดมินเท่านั้นที่สามารถเผยแพร่โพสต์ --
ผู้ติดตามแค่อ่านตาม

### ค้นหาและเข้าร่วมช่อง

1. สลับไปแท็บ "ช่อง"
2. เปิดแท็บ "ค้นหา"
3. ค้นหาช่องที่มีอยู่ตามชื่อหรือหัวข้อ
4. แตะช่องหนึ่งแล้ว "ติดตาม"

ช่องสามารถกรองตามภาษาได้ ช่องบางช่องถูกทำเครื่องหมาย
เป็น "ไม่เหมาะสำหรับผู้เยาว์" -- เหล่านี้มองเห็นได้ก็ต่อเมื่อ
คุณได้ยืนยันในโปรไฟล์ของคุณว่าคุณอายุมากกว่า 18 ปี

### สร้างช่องของตัวเอง

1. สลับไปแท็บ "ช่อง"
2. แตะปุ่มบวก
3. ป้อนชื่อช่อง (ต้องไม่ซ้ำกันทั่วทั้งเครือข่าย)
4. เลือกภาษาและว่าช่องจะเป็นสาธารณะหรือส่วนตัว
5. ทางเลือก: เพิ่มคำอธิบายและภาพ
6. แตะ "สร้าง"

สำหรับช่องสาธารณะคุณสามารถกำหนดได้ว่าเนื้อหาจะถูกจัดประเภท
เป็น "ไม่เหมาะสำหรับผู้เยาว์" หรือไม่

### รายงานเนื้อหา

หากคุณสังเกตเนื้อหาที่ไม่เหมาะสมในช่องสาธารณะ คุณสามารถ
รายงานมันได้ Cleona ใช้ระบบตรวจสอบแบบกระจาย: รายงาน
ถูกประเมินโดยสมาชิกที่สุ่มเลือกของเครือข่าย (คล้าย "คณะลูกขุน")
หากพบการละเมิด ช่องจะได้รับคำเตือน หากมีการละเมิดซ้ำ
มันจะถูกลดระดับในดัชนีค้นหาหรือถูกบล็อก

### ช่องระบบ

Cleona มีช่องระบบในตัวสองช่อง:

- **Bug Log:** เมื่อ Cleona ตรวจพบข้อผิดพลาด มันจะถามคุณว่าคุณ
  ต้องการส่งรายงานข้อผิดพลาดหรือไม่; ก่อนหน้านั้นคุณเห็นชัดว่า
  อะไรจะถูกเผยแพร่ รายงานเหล่านี้
  ลงในช่อง Bug Log ที่ชุมชนสามารถดูได้ รายงานหนึ่งไม่มีชื่อ
  และไม่มีเนื้อหาของบทสนทนาของคุณ แต่มีนามแฝงหนึ่ง ในเบต้า
  มันระบุเพิ่มรหัสประจำตัวผู้ใช้ (User-ID) ของคุณ เพื่อให้นักพัฒนา
  ถามต่อได้ คุณสามารถ
  ส่งรายงาน log ด้วยมือได้ (พร้อมกล่องโต้ตอบตัวอย่างและ
  ความยินยอมอย่างชัดแจ้ง)
- **Feature Requests:** ที่นี่ผู้ใช้สามารถส่งความต้องการฟังก์ชันและ
  ลงคะแนนข้อเสนอที่มีอยู่ ข้อเสนอถูกจัดเรียงตามคะแนน

คอมพิวเตอร์แต่ละเครื่องเก็บสูงสุด 25 MB ต่อช่องระบบหนึ่งช่อง
โทรศัพท์แต่ละเครื่องสูงสุด 5 MB; เมื่อเต็ม สิ่งที่เก่าที่สุด
ไปก่อน -- ไม่ใช่สิ่งที่คุณเคยดูแล้วเด็ดขาด

## 7. การโทร

### เริ่มโทรด้วยเสียง

1. เปิดแชทกับผู้ติดต่อที่คุณต้องการโทร
2. แตะสัญลักษณ์โทรศัพท์ในแถบบน
3. รอจนคู่สนทนารับสาย

ระหว่างการสนทนาคุณเห็นไทม์ไลน์ ระยะเวลาการสนทนา
และเข้าถึงการปิดเสียงและลำโพง

เพื่อวางสาย แตะปุ่มวางสายสีแดง

หากคุณเห็น "ติดต่อไม่ได้"
แสดงว่าอุปกรณ์ของอีกฝ่ายติดต่อไม่ได้ในขณะนี้ เช่น iPhone
ที่แอปไม่ได้เปิดอยู่ ให้ส่งข้อความแทน

### เริ่มโทรด้วยวิดีโอ

1. เปิดแชทกับผู้ติดต่อ
2. แตะสัญลักษณ์กล้องในแถบบน
3. ภาพวิดีโอของคุณปรากฏในหน้าต่างเล็ก ภาพของคู่สนทนาของคุณ
   ในพื้นที่ใหญ่

คุณสามารถสลับระหว่างกล้องหน้าและกล้องหลังระหว่างการสนทนา

### สายเข้า

เมื่อใครโทรหาคุณ หน้าต่างแจ้งเตือนปรากฏพร้อมชื่อ
ของผู้โทร คุณสามารถ:

- **รับสาย** -- การสนทนาเริ่มต้น
- **ปฏิเสธ** -- ผู้โทรได้รับแจ้ง

หากคุณกำลังอยู่ในการสนทนา สายใหม่จะไม่ส่งเสียงเรียก;
คุณได้รับข้อความ "สายที่ไม่ได้รับ" แทน ข้อนี้ใช้เช่นกันกับ
สายกลุ่มที่คุณไม่ได้รับ -- ข้อความอยู่ในแชทกลุ่ม

หากมีคนโทรหาตัวตนหนึ่งของคุณที่ไม่ได้แสดงอยู่ในขณะนี้
มันก็ยังส่งเสียงเรียก; หน้าจอสายระบุว่าตัวตนใดของคุณ
ที่ถูกโทร

บน iPhone จะมีเสียงเรียกเข้าเฉพาะขณะที่แอปเปิดอยู่
ผู้ที่โทรหาคุณขณะที่แอปไม่ได้เปิดอยู่จะเห็น "ติดต่อไม่ได้"
หลังผ่านไป 10 วินาที ทันทีที่คุณเปิดแอป
คุณจะพบข้อความสายที่ไม่ได้รับ

### การโทรกลุ่ม

คุณสามารถจัดการโทรกลุ่มที่หลายคนเข้าร่วมในเวลาเดียวกัน
การโทรถูกจัดระเบียบผ่านต้นไม้ส่งต่ออัจฉริยะ เพื่อให้ผู้เข้าร่วม
ไม่ต้องเชื่อมต่อโดยตรงกับทุกคน การสนทนาทั้งหมดเข้ารหัสตลอด

สมาชิกกลุ่มทุกคนสามารถเริ่มสายกลุ่มได้ ผู้เข้าร่วมสองคน
ที่ไม่ใช่ผู้ติดต่อของกัน จะไม่เห็นที่อยู่อินเทอร์เน็ตของอีกฝ่ายเด็ดขาด:
เสียงและภาพของพวกเขาวิ่งผ่านผู้เข้าร่วมหนึ่งที่เป็นผู้ติดต่อ
กับทั้งคู่ หากไม่มีคนเช่นนั้น ทั้งสองจะไม่เชื่อมต่อกัน และช่อง
ภาพบอกว่า "ไม่มีผู้ติดต่อร่วมในสายนี้" หากตัวส่งต่อหนึ่ง
ทำงานเต็มที่ เสียงยังอยู่ แต่วิดีโอหายไปสำหรับคู่นั้น

### การเข้ารหัสสำหรับการโทร

การโทรทั้งหมดถูกเข้ารหัสด้วยกุญแจใช้ครั้งเดียวที่มีอยู่เฉพาะ
ระหว่างการสนทนา หลังวางสาย กุญแจเหล่านี้ถูกลบทันที
ไม่มีใครสามารถถอดรหัสการสนทนาในอดีตภายหลังได้

พูดตรงๆ: การโทรทำงานโดยตรงระหว่างอุปกรณ์เท่าที่เป็นไปได้
เพราะแม้ความหน่วงเล็กน้อยก็รบกวนการพูด ต่างจากข้อความ
ผู้ให้บริการอินเทอร์เน็ตของคุณจึงสามารถเห็นระหว่างการโทร
ว่าคุณเชื่อมต่อกับที่อยู่อินเทอร์เน็ตใด สิ่งที่คุณพูด มันเห็นไม่ได้

ระหว่างการโทร ผู้ติดต่อของคุณก็เห็นที่อยู่อินเทอร์เน็ตของคุณด้วย
หากคุณไม่ต้องการเช่นนั้นกับผู้ติดต่อหนึ่ง ให้ปิด "อนุญาตการโทร"
ในเมนูของเขา (ค่าตั้งต้น: เปิด) หากคุณปิดในภายหลัง
ที่อยู่ที่เขาเคยเห็นแล้วก็ยังเป็นที่รู้กันอยู่

## 8. ปฏิทิน

Cleona มีปฏิทินในตัวที่ทำงานแบบเข้ารหัสและกระจายอย่างสมบูรณ์ --
โดยไม่มีบริการคลาวด์

### มุมมอง

ปฏิทินมีห้ามุมมอง: วัน สัปดาห์ เดือน ปี และมุมมองงาน
สลับระหว่างมันผ่านแท็บที่ด้านบนของหน้าจอปฏิทิน

### สร้างนัดหมาย

แตะช่องเวลาหรือใช้ปุ่มเพิ่มเพื่อสร้างนัดหมายใหม่ คุณสามารถ
ป้อนชื่อ วันที่ เวลา สถานที่ และบันทึก นัดหมายถูกเก็บ
เข้ารหัสบนอุปกรณ์ของคุณ

### นัดหมายที่เกิดซ้ำ

นัดหมายสามารถเกิดซ้ำรายวัน รายสัปดาห์ รายเดือน หรือรายปี
คุณสามารถปรับรูปแบบ (เช่น อังคารที่สองของทุกสัปดาห์ วันแรกของทุกเดือน)
และกำหนดวันสิ้นสุดหรือจำนวนครั้งที่เกิดซ้ำ

### เชิญผู้ติดต่อ

เมื่อสร้างหรือแก้ไขนัดหมาย คุณสามารถเชิญผู้ติดต่อ Cleona ของคุณ
พวกเขาได้รับคำเชิญปฏิทินที่เข้ารหัสและสามารถตอบด้วย
ไป ไม่ไป หรืออาจไป การเปลี่ยนแปลงนัดหมายจะถูกส่ง
โดยอัตโนมัติให้ผู้รับเชิญทั้งหมด

### แสดงว่าง/ติด

คุณสามารถแบ่งปันความพร้อมของคุณกับผู้ติดต่อโดยไม่เปิดเผย
รายละเอียดนัดหมาย มีสามระดับความเป็นส่วนตัว: รายละเอียดเต็ม
เฉพาะช่วงเวลา หรือซ่อน คุณสามารถตั้งค่าเริ่มต้นและ
แทนที่เป็นรายผู้ติดต่อ

### การแจ้งเตือน

นัดหมายสามารถมีการแจ้งเตือนที่กระตุ้นการแจ้งเตือนระบบ
ก่อนนัดหมายเริ่ม คุณสามารถเลื่อนการแจ้งเตือนหากต้องการ

### ซิงค์ปฏิทินภายนอก

Cleona สามารถซิงค์กับบริการปฏิทินภายนอก:

- **CalDAV** -- เชื่อมต่อกับเซิร์ฟเวอร์ใดๆ ที่รองรับ CalDAV (Nextcloud,
  Radicale ฯลฯ)
- **Google Calendar** -- ซิงค์ผ่าน Google Calendar API
  ด้วยการยืนยันตัวตน OAuth2 ที่ปลอดภัย
- **เซิร์ฟเวอร์ CalDAV ในเครื่อง** -- Cleona สามารถเริ่มเซิร์ฟเวอร์ CalDAV ในเครื่องบน
  อุปกรณ์ของคุณ เพื่อให้แอปปฏิทินบนเดสก์ท็อป (Thunderbird, Outlook,
  Apple Calendar, Evolution) ซิงค์กับปฏิทิน Cleona ของคุณได้
- **ปฏิทินระบบ Android** -- นัดหมายจาก Cleona สามารถถูก
  ถ่ายโอนไปยังแอปปฏิทินในตัวของอุปกรณ์ Android ของคุณ
- **ไฟล์ ICS** -- นำเข้าและส่งออกนัดหมายในรูปแบบ
  iCalendar มาตรฐาน

### ส่งออก PDF

คุณสามารถพิมพ์หรือส่งออกมุมมองปฏิทินใดๆ (วัน สัปดาห์ เดือน ปี) เป็น
เอกสาร PDF

## 9. แบบสำรวจ

คุณสามารถสร้างแบบสำรวจในแชทหรือกลุ่มใดๆ เพื่อรวบรวมความคิดเห็น
หรือวางแผนวันที่

### ประเภทแบบสำรวจ

Cleona รองรับแบบสำรวจห้าประเภท:

- **เลือกคำตอบเดียว** -- ผู้เข้าร่วมเลือกหนึ่งตัวเลือก
- **เลือกหลายคำตอบ** -- ผู้เข้าร่วมสามารถเลือกหลายตัวเลือก
- **แบบสำรวจวันที่** -- หาวันที่ที่เหมาะกับทุกคน ผู้เข้าร่วมแต่ละคน
  ทำเครื่องหมายวันที่เป็น ว่าง อาจว่าง หรือ ไม่ว่าง
- **สเกล** -- ให้คะแนนบางอย่างบนสเกลตัวเลข (เช่น 1 ถึง 5)
- **ข้อความอิสระ** -- ผู้เข้าร่วมเขียนคำตอบของตัวเอง

### สร้างแบบสำรวจ

เปิดแชทและแตะสัญลักษณ์แบบสำรวจ (หรือใช้เมนูแนบ) เลือก
ประเภทแบบสำรวจ ร่างคำถามและตัวเลือกของคุณ และส่งแบบสำรวจ
มันปรากฏเป็นข้อความในแชท

### ลงคะแนน

แตะแบบสำรวจเพื่อลงคะแนน คุณสามารถเปลี่ยนหรือถอนคะแนนของคุณ
ได้ตลอดเวลา

### การลงคะแนนไม่ระบุตัวตน

แบบสำรวจสามารถตั้งค่าสำหรับการลงคะแนนไม่ระบุตัวตน เมื่อเปิดใช้งาน
คะแนนจะเป็นไม่ระบุตัวตนทางการเข้ารหัส -- ไม่มีใคร แม้แต่ผู้สร้าง
แบบสำรวจ สามารถเห็นว่าใครลงคะแนนอะไร จำนวนคะแนนยังคง
มองเห็นได้

### แบบสำรวจวันที่ไปปฏิทิน

เมื่อแบบสำรวจวันที่เสร็จสิ้น วันที่ที่ชนะสามารถถูกเปลี่ยนเป็น
รายการปฏิทินด้วยการแตะครั้งเดียว

## 10. หลายตัวตน

### ทำไมต้องหลายตัวตน?

จินตนาการว่าคุณต้องการแยกชีวิตการทำงานและชีวิตส่วนตัวของคุณ --
คล้ายกับการมีหมายเลขโทรศัพท์สองหมายเลข แต่ไม่ต้องมีโทรศัพท์เครื่องที่สอง
ใน Cleona คุณสามารถใช้ตัวตนหลายตัวบนอุปกรณ์หนึ่ง ตัวตนแต่ละตัว
มีชื่อ รูปโปรไฟล์ ผู้ติดต่อ และบทสนทนาของตัวเอง

### สร้างตัวตนใหม่

1. ในแถบบนคุณเห็นตัวตนปัจจุบันของคุณเป็นแท็บ
2. แตะเครื่องหมายบวก (+) ทางขวาของแท็บตัวตนของคุณ
3. ป้อนชื่อสำหรับตัวตนใหม่
4. เสร็จแล้ว -- ตัวตนใหม่ใช้งานได้ทันที

### สลับระหว่างตัวตน

เพียงแตะแท็บตัวตนในแถบบน การสลับทันที --
ไม่ต้องรอ ไม่ต้องโหลดใหม่

### ทั้งหมดทำงานพร้อมกัน

ประเด็นสำคัญ: ตัวตนทั้งหมดของคุณใช้งานอยู่พร้อมกัน แม้
คุณกำลังแสดงเป็น "ทำงาน" ในขณะนี้ ตัวตน "ส่วนตัว"
ของคุณยังคงรับข้อความอยู่ คุณไม่พลาดอะไร ไม่ว่าคุณ
จะเลือกตัวตนใดอยู่ในขณะนี้

### หน้ารายละเอียดตัวตน

เมื่อคุณแตะแท็บของตัวตนที่ใช้งานอยู่ในขณะนี้ หน้ารายละเอียดจะเปิดขึ้น
ที่นี่คุณสามารถ:

- แสดง QR code ของคุณสำหรับผู้ติดต่อ
- เปลี่ยนหรือลบรูปโปรไฟล์ของคุณ
- เพิ่มคำอธิบายโปรไฟล์
- เปลี่ยนชื่อที่แสดงของคุณ
- เลือกดีไซน์ (สกิน) สำหรับตัวตนนี้
- ลบตัวตน หากคุณไม่ต้องการมันอีก

### ลบตัวตน

เมื่อคุณลบตัวตน ผู้ติดต่อของคุณจะได้รับแจ้งเกี่ยวกับมัน ตัวตน
และข้อมูลที่เกี่ยวข้องทั้งหมดถูกลบจากอุปกรณ์ของคุณ กระบวนการนี้
ไม่สามารถย้อนกลับได้

## 11. หลายอุปกรณ์

### ตัวตนหนึ่ง อุปกรณ์หนึ่ง -- สำหรับตอนนี้

วันนี้ตัวตนหนึ่งทำงานบนอุปกรณ์หนึ่ง อุปกรณ์ที่สอง
สำหรับตัวตนเดียวกันจะมากับเวอร์ชันถัดไป; ในการตั้งค่า
ภายใต้ "อุปกรณ์" -> "จัดการอุปกรณ์" "จับคู่อุปกรณ์เพิ่มเติม"
จึงยังเขียนไว้ว่า "ยังไม่พร้อมใช้งาน"

เมื่อมันมาถึง จะเป็นดังนี้: อุปกรณ์ทั้งหมดมีสิทธิ์เท่ากัน
ไม่มีอุปกรณ์หลัก คุณตั้งค่าอุปกรณ์เพิ่มเติมด้วย 24 คำของคุณ
และหนึ่งในอุปกรณ์เดิมของคุณให้ความยินยอม สูงสุด 5 อุปกรณ์

หากคุณป้อน 24 คำของคุณบนอุปกรณ์ใหม่วันนี้ คุณย้ายไป: ตัวตน
ถูกกู้คืนบนอุปกรณ์ใหม่ และอุปกรณ์เดิมของคุณลบตัวตนนั้น
จากตัวเองในภายหลัง (ดูบทที่ 12)

บนหลายอุปกรณ์ วันนี้คุณสามารถใช้ตัวตนต่างกันได้
(บทที่ 10)

### สร้างกุญแจใหม่ให้ตัวตน

หากคุณสงสัยว่ามีใครได้กุญแจของคุณไป คุณสามารถสร้างกุญแจ
ใหม่ได้ภายใต้ "จัดการอุปกรณ์" -> "หมุนกุญแจ" ผู้ติดต่อของคุณ
ได้รับแจ้ง และคำเชิญที่เปิดอยู่ของคุณถูกเพิกถอน สำคัญ: หลังจาก
นั้น 24 คำเพียงลำพังสร้างกุญแจเก่ากลับมาได้เท่านั้น จึงควรสร้าง
แพ็กเกจกู้คืนใหม่ทันทีหลังจากนั้น; การกู้คืนทำได้
เฉพาะพร้อมกับแพ็กเกจนี้แล้ว

## 12. การกู้คืน

### ใช้วลีรหัสฟื้น

เมื่อคุณสูญเสียอุปกรณ์หรือตั้งค่าอันใหม่:

1. ติดตั้ง Cleona บนอุปกรณ์ใหม่
2. เลือก "กู้คืน" เมื่อเริ่มต้น
3. ป้อน 24 คำของคุณ
4. Cleona สร้างตัวตนทั้งหมดของคุณจากมัน -- ด้วยกุญแจ
   เดียวกับก่อนหน้า สำหรับผู้ติดต่อของคุณ คุณคือคนเดิม

### สิ่งที่กลับมา -- และสิ่งที่ไม่กลับมา

ตัวตนของคุณอยู่ใน 24 คำ ผู้ติดต่อและประวัติของคุณไม่ใช่
สิ่งที่กลับมาคือการเข้าถึงเครือข่ายของคุณผ่าน **แพ็กเกจกู้คืน**:
อุปกรณ์ของคุณฝากแพ็กเกจเล็กที่เข้ารหัสไว้ในเครือข่าย เฉพาะ 24
คำของคุณเท่านั้นที่หาและเปิดมันได้ ในนั้นระบุสิ่งที่อุปกรณ์ใหม่
ของคุณต้องการเพื่อติดต่อผู้ติดต่อของคุณอีกครั้ง และสิ่งที่ค้างอยู่
ในเครือข่ายระหว่างนั้นเพื่อคุณ ไม่มีผู้ติดต่อใดต้องออนไลน์สำหรับสิ่งนี้

การกู้คืนไม่นำประวัติแชทเดิมกลับมา

แพ็กเกจกู้คืนมีอายุ 7 วันและถูกอุปกรณ์ของคุณต่ออายุตราบใด
ที่มันทำงานอยู่; ในการตั้งค่าคุณเห็นว่ามันใช้ได้ถึงเมื่อใด หาก
ไม่มีอุปกรณ์ใดของคุณทำงานเกิน 7 วัน มันก็หมดอายุ แล้ว 24 คำ
ก็ยังกู้คืนตัวตนของคุณได้อยู่ แต่คุณต้องเชิญผู้ติดต่อของคุณใหม่;
สิ่งที่ค้างอยู่ในเครือข่ายระหว่างนั้นเพื่อคุณสูญหาย

### กู้คืนหมายถึงย้าย

เมื่ออุปกรณ์เดิมของคุณพบภายหลังว่าตัวตนถูกกู้คืนไปที่อื่น
มันจะลบตัวตนนั้นจากตัวเอง -- พร้อมทั้งประวัติของตัวตน ดังนั้น:
ใครก็ตามที่มี 24 คำของคุณ สามารถดึงตัวตนของคุณจาก
อุปกรณ์ของคุณด้วยวิธีนี้ จนกว่าผู้ติดต่อจะกลับมาครบ แอปเตือนคุณ;
ด้วย "เสร็จสิ้นและต่ออายุคีย์" คุณจบการกู้คืนด้วยตัวเอง

### สิ่งที่ไม่มีใครกู้คืนได้

นี่สำคัญ และเราจึงระบุมันให้ชัด:

- **ไม่มีใครนอกจากคุณสามารถกู้คืนตัวตนของคุณได้.** ไม่ใช่
  นักพัฒนา ไม่ใช่ฝ่ายสนับสนุน และไม่ใช่ผู้ติดต่อของคุณ -- ไม่ว่า
  จะมีกี่คนก็ตาม ไม่มีกุญแจหลักและไม่มีส่วนใดของกุญแจของคุณ
  ที่ถูกฝากไว้กับผู้อื่น
- **หากคุณทำ 24 คำหายและไม่มีอุปกรณ์เหลือ ตัวตนของคุณ
  หายไป.** ทางเลือกเดียวคือสร้างใหม่และ
  เชิญผู้ติดต่อของคุณใหม่

การป้องกันที่ดีที่สุด: จด 24 คำลงบนกระดาษและเก็บรักษาไว้
ให้ปลอดภัย

## 13. การตั้งค่า

คุณเข้าถึงการตั้งค่าผ่านสัญลักษณ์เฟืองที่มุมขวาบน

### การแจ้งเตือนและเสียงเรียกเข้า

- เลือกจากเสียงเรียกเข้าหกแบบสำหรับสายเข้า
- ตั้งเสียงข้อความ
- บนอุปกรณ์ Android คุณสามารถเปิดหรือปิด
  การสั่นเพิ่มเติมได้
- **"ปิดเสียงทั้งหมด"** ทำให้บนอุปกรณ์นี้ไม่มีข้อความใด
  เรียกเข้า สั่น หรือแจ้งเตือนอีก -- สำหรับตัวตนทั้งหมด การโทร
  ยังส่งเสียงเรียกต่อไป
- **"ช่วงเวลาเงียบ"** คุณกำหนดต่อตัวตนด้วย เวลาเริ่ม/สิ้นสุด
  ในช่วงเวลานี้ไม่มีข้อความของตัวตนนี้เรียกเข้า สั่น หรือแจ้งเตือน;
  ข้อความยังมาถึงตามปกติ
- **"การแจ้งเตือนโดยไม่มีเนื้อหา"** (ค่าตั้งต้น: ปิด) แสดงเพียงว่า
  ข้อความ คำเชิญ หรือการแจ้งเตือนความจำหนึ่งมาถึง -- โดยไม่มี
  ผู้ส่ง ชื่อ และข้อความ การโทรยังแสดงชื่อต่อไป
- สิ่งที่มาถึงพร้อมกันทั้งหมดหลังการเริ่ม Cleona แจ้งใน
  การแจ้งเตือนรวมหนึ่ง ("5 ข้อความใหม่ใน 2 บทสนทนา");
  ทุกสิ่งที่มาภายหลังทีละรายการ การแตะการแจ้งเตือนข้อความ
  หนึ่งเปิดบทสนทนา แม้ในตัวตนอื่น

### ดีไซน์ (สกิน)

Cleona มีดีไซน์ต่างกันสิบแบบ: Teal, Ocean, Sunset, Forest,
Amethyst, Fire, Storm, Slate, Gold และ Contrast ดีไซน์ Contrast ผ่าน
ระดับการเข้าถึงได้สูงสุด (WCAG AAA) และอ่านง่ายเป็นพิเศษ
สำหรับผู้มีสายตาจำกัด

ตัวตนแต่ละตัวสามารถมีดีไซน์ของตัวเอง คุณเปลี่ยนดีไซน์ใน
หน้ารายละเอียดตัวตน (แตะแท็บตัวตนที่ใช้งานอยู่)

เพิ่มเติม คุณสามารถสลับระหว่างธีมสว่าง มืด และตามระบบ
ในการตั้งค่าภายใต้ "ลักษณะ"

### เปลี่ยนภาษา

Cleona มีให้ใช้ใน 34 ภาษา รวมถึงภาษาที่เขียนจากขวาไปซ้าย
(เช่น อาหรับ ฮีบรู) เปลี่ยนภาษาใน
การตั้งค่าภายใต้ "ภาษา"

### การเก็บสื่อถาวร

หากคุณมีที่เก็บข้อมูลเครือข่าย (NAS) หรือโฟลเดอร์ที่แชร์ที่บ้าน
Cleona สามารถย้ายสื่อของคุณไปที่นั่นโดยอัตโนมัติ รองรับ
SMB, SFTP, FTPS และ WebDAV

นี่คือวิธีที่การจัดเก็บแบบขั้นบันไดทำงาน:
- 30 วันแรก: ทุกอย่างอยู่บนอุปกรณ์ของคุณ
- หลัง 30 วัน: ภาพตัวอย่างอยู่บนอุปกรณ์ ต้นฉบับถูก
  เก็บถาวร
- หลัง 90 วัน: เหลือเฉพาะภาพตัวอย่างเล็กบนอุปกรณ์
- หลังหนึ่งปี: เหลือเฉพาะตัวยึดตำแหน่ง ต้นฉบับอยู่
  ปลอดภัยในที่เก็บถาวร

คุณสามารถแตะสื่อที่เก็บถาวรได้ตลอดเวลาเพื่อเรียกกลับ --
โดยมีเงื่อนไขว่าคุณเชื่อมต่อกับเครือข่ายภายในบ้านของคุณ สื่อที่สำคัญ
เป็นพิเศษสามารถปักหมุดเพื่อให้ไม่ถูกย้ายออก

ภายใต้ "งบเก็บข้อมูล" คุณกำหนดว่าสื่อกี่ MB จะอยู่บนอุปกรณ์
(ค่าตั้งต้น: 100 MB บนโทรศัพท์, 2 GB บนคอมพิวเตอร์) เมื่อเต็ม
สื่อที่ไม่ได้ปักหมุดที่เก่าที่สุดจะถูกเก็บถาวรก่อน ต้นฉบับ
ถูกลบก็ต่อเมื่อมันอยู่ในที่เก็บถาวรอย่างปลอดภัยแล้วเท่านั้น --
ข้อความตัวอักษรยังคงอยู่เสมอ

### การถอดข้อความสำหรับข้อความเสียง

เมื่อเปิดใช้งาน ข้อความเสียงของคุณถูกแปลงเป็นข้อความในเครื่องบน
อุปกรณ์ของคุณ (ด้วยโมเดลโอเพนซอร์ส Whisper) ข้อความที่ถอดแล้ว
ถูกส่งพร้อมการบันทึกให้คู่สนทนาของคุณ การถอดเกิดขึ้นทั้งหมดบน
อุปกรณ์ของคุณ -- ไม่มีข้อมูลไปยังบริการภายนอก

โมเดลใด (tiny, base, small) ที่จะถูกดาวน์โหลด คุณตั้งครั้งเดียว
สำหรับอุปกรณ์; ภาษา (อัตโนมัติหรือกำหนดคงที่) ต่อตัวตน

### ดาวน์โหลดอัตโนมัติ

คุณสามารถตั้งค่าว่าสื่อขนาดใดขึ้นไปควรถูกดาวน์โหลดโดยอัตโนมัติ
ด้วยวิธีนี้ ตัวอย่างเช่น คุณสามารถให้ภาพโหลดอัตโนมัติ แต่
ตัดสินใจด้วยมือสำหรับวิดีโอขนาดใหญ่

### อุปกรณ์

ภายใต้ "อุปกรณ์" -> "จัดการอุปกรณ์" คุณเห็นอุปกรณ์นี้ การจับคู่
อุปกรณ์เพิ่มเติมจะมากับเวอร์ชันถัดไป (บทที่ 11)

### เครือข่าย

Cleona ไม่ต้องการการตั้งค่าเครือข่ายเพื่อทำงาน มีสวิตช์
เครือข่ายสามตัว:

- **การเปิดพอร์ตที่เราเตอร์** (ค่าตั้งต้น: เปิด) Cleona ขอเราเตอร์
  ของคุณเองเปิดประตูให้ Cleona หากสำเร็จ อุปกรณ์ของคุณ
  สามารถเข้าถึงได้ดีกว่าสำหรับผู้อื่นและช่วยเครือข่าย Cleona คุย
  กับเราเตอร์ของคุณเท่านั้น ไม่ใช่อินเทอร์เน็ต
- **รายการที่อยู่สาธารณะ** (ค่าตั้งต้น: เปิด) หากอุปกรณ์ของคุณยัง
  มีเพื่อนบ้านน้อยเกินไป มันค้นหาจุดเข้าเพิ่มเติมในสมุด
  สาธารณะ (Nostr) และหากมันเองเข้าถึงได้ดี มันลงทะเบียน
  ตัวเองที่นั่น รายการมีที่อยู่ ไม่มีชื่อและไม่มีผู้ติดต่อ
  หากคุณปิดมัน อุปกรณ์ของคุณหาเพื่อนบ้านได้เฉพาะผ่าน
  คำเชิญ เครือข่ายท้องถิ่น และเพื่อนบ้านที่มันรู้จักแล้ว
- **แพ็กเกจพรางน้อยลงใน Wi-Fi** (ค่าตั้งต้น: ปิด) ใน Wi-Fi
  หรือสายเคเบิลคุณสามารถปิดแพ็กเกจพรางที่ว่าง แต่
  จากนั้นจะเห็นอีกว่าคุณกำลังเขียนเมื่อใด ไม่มีสวิตช์
  เช่นนี้บนข้อมูลมือถือ -- ที่นั่น Cleona ส่งแพ็กเกจพราง
  เพียงหนึ่งแพ็กเกจต่อนาทีอยู่แล้ว

กระแสพรางโดยรวมไม่สามารถปิดได้ นั่นตั้งใจ: ก็ต่อเมื่อ
มันทำงานตลอดเวลา กิจกรรมของอุปกรณ์คุณจึงไม่บอกอะไรเลยว่า
คุณกำลังเขียนอยู่หรือไม่

เหนือสวิตช์ทั้งสามอยู่ **โหมดประหยัดข้อมูล**: บนข้อมูลมือถือ
Cleona เสนอมัน แต่ไม่เปิดเองเด็ดขาด มันประหยัดข้อมูล แต่
อุปกรณ์ของคุณมองจากภายนอกจะถูกจำแนกได้ง่ายขึ้น

ใต้นั้นคุณตั้งค่า **"แคชสำหรับสื่อของผู้อื่น"**: อุปกรณ์
ของคุณเก็บชิ้นที่เข้ารหัสของสื่อของผู้อื่นสูงสุด 7 วัน เพื่อให้
พวกมันถึงผู้รับ (ค่าตั้งต้น: 100 MB บนโทรศัพท์, 1 GB บน
คอมพิวเตอร์) การตั้งขนาดเล็กลงคืนพื้นที่ทันที -- ชิ้นที่เก่า
ที่สุดก่อน

## 14. ความปลอดภัย

### การเข้ารหัส Post-Quantum หมายถึงอะไร?

การเข้ารหัสปัจจุบันอยู่บนปัญหาทางคณิตศาสตร์ที่ยากต่อการแก้
อย่างยิ่งสำหรับคอมพิวเตอร์ปกติ คอมพิวเตอร์ควอนตัมอาจแก้
ปัญหาบางส่วนของปัญหาเหล่านี้ได้อย่างรวดเร็วในอนาคต การเข้ารหัส
Post-Quantum ใช้วิธีการเพิ่มเติมที่ทนต่อคอมพิวเตอร์ควอนตัมด้วย

Cleona ผสมทั้งสองแนวทาง: การเข้ารหัสคลาสสิกเพื่อ
ความน่าเชื่อถือและวิธี Post-Quantum เพื่อความรองรับอนาคต ด้วยวิธีนี้
คุณได้รับการปกป้องจากภัยคุกคามทั้งปัจจุบันและอนาคตพร้อมกัน

กุญแจแยกต่างหากถูกสร้างขึ้นสำหรับข้อความแต่ละรายการ แม้ผู้โจมตี
แกะกุญแจของข้อความหนึ่งได้ เขาก็ไม่สามารถอ่านข้อความ
อื่นใดได้ด้วยมัน

### ทำไมไม่มีเซิร์ฟเวอร์จึงปลอดภัยกว่า

กับแอปส่งข้อความแบบดั้งเดิม ข้อความของคุณผ่านเซิร์ฟเวอร์
ของผู้ให้บริการ แม้มันอาจถูกเข้ารหัสที่นั่น: ผู้ให้บริการเข้าถึง
ข้อมูลเมตาได้ (ใครสื่อสารกับใคร เมื่อใด บ่อยเพียงใด จากที่ใด)
และอาจต้องส่งมอบเหล่านี้ตามคำสั่งศาล

กับ Cleona ไม่มีจุดศูนย์กลางเช่นนั้น ไม่มีที่ใดที่ข้อมูลเมตา
ทั้งหมดมารวมกัน และไม่มีสมุดที่ใครสามารถค้นหาได้ว่าคุณคือใคร
หรือคุณรู้จักใคร

### ใครเห็นว่าคุณกำลังเขียนกับใคร?

การเข้ารหัสปกป้อง **สิ่งที่** คุณเขียน สำคัญเท่ากันคือไม่มี
ผู้สังเกตคนใดคนหนึ่งรู้ **กับใคร** และ **เมื่อใด** ที่คุณเขียน
Cleona รับผิดชอบสิ่งนั้นดังนี้:

- **บนอินเทอร์เน็ตไม่เคยโดยตรง.** หากอุปกรณ์ของคุณส่งข้อความ
  โดยตรงไปยังที่อยู่อินเทอร์เน็ตของคู่สนทนาของคุณ ผู้ให้บริการของคุณสามารถ
  เห็นว่าคุณกำลังเขียนกับใคร ดังนั้นข้อความบนอินเทอร์เน็ตจึงผ่าน
  เพื่อนบ้านถาวรของคุณเสมอ: ของคุณและของคู่สนทนาของคุณ
- **เพื่อนบ้านที่คุณไว้วางใจ.** เพื่อนบ้านถาวรของคุณคือ เท่าที่เป็นไปได้
  อุปกรณ์ของผู้ติดต่อของคุณเอง -- สูงสุดสามที่เข้าถึงได้จากภายนอก
  ในขณะนี้ หากตัวหนึ่งหายไป ผู้ติดต่ออื่นขยับขึ้นมาแทน
  ผู้ติดต่อไม่สามารถซื้อด้วยเซิร์ฟเวอร์; โหนดใดๆ ใน
  เครือข่ายได้ หากคุณยังไม่มีผู้ติดต่อที่เข้าถึงได้ Cleona ใช้
  เพื่อนบ้านอื่น คำเชิญของคุณไม่เคยระบุผู้ติดต่อของคุณคนใด
  เพื่อให้ไม่มีใครเรียนรู้ที่อยู่ของเพื่อนผ่านพวกเขา
- **รหัสแทนชื่อ.** เพื่อนบ้านเห็นไม่มีชื่อและไม่มีตัวระบุ
  เฉพาะรหัส มันใช้กับคุณทั้งคู่พอดี ในทิศทางเดียว
  ในหนึ่งวัน -- วันถัดไปมันเป็นอันอื่น เพื่อนบ้านของคุณรู้
  ว่าแพ็กเกจมาจากไหน แต่ไม่รู้ว่ามันไปที่ไหนในที่สุด เพื่อนบ้าน
  ของคู่สนทนาของคุณรู้ว่ามันไปที่ไหน แต่ไม่รู้ว่ามันมาจากไหน
  โดยปกติไม่มีใครระหว่างทางเห็นทั้งสองปลาย
- **กระแสพราง.** อุปกรณ์ของคุณส่ง ในช่วงห่างไม่สม่ำเสมอ
  แพ็กเกจพรางให้เพื่อนบ้านของมัน พวกมันใหญ่เท่ากับ
  แพ็กเกจจริง ผ่านพอร์ตเดียวกัน และมองจากภายนอกไม่อาจ
  แยกจากพวกมันได้ ว่ามนุษย์กำลังเขียนอยู่หรืออุปกรณ์แค่ทำงานอยู่
  ไม่อาจบอกได้ ข้อความของคุณไม่เคยรอกระแสพราง --
  มันออกตัวทันที มันทำงานข้างกายเท่านั้น

**กระแสพรางเสียค่าใช้จ่ายเท่าใด:** ใน Wi-Fi ประมาณ 13 MB ต่อวัน
บนข้อมูลมือถือ Cleona ส่งแพ็กเกจพรางเพียงหนึ่งแพ็กเกจต่อนาที
นั่นคือประมาณ 1.7 MB ต่อวัน เหตุผลสำหรับการจำกัดบนข้อมูลมือถือ
ไม่ใช่ปริมาณข้อมูล แต่คือแบตเตอรี่: ทุกแพ็กเกจปลุก
โมเด็มวิทยุ

**สิ่งที่ Cleona ไม่สามารถปกปิดได้** -- พูดตรงๆ:

- ไม่มีผู้สังเกต **คนเดียว** เห็นว่าใครกำลังเขียนกับใคร -- ไม่ใช่
  ผู้ให้บริการของคุณหรือโหนดระหว่างทาง แต่ผู้ที่ **ตรวจสอบทั้งสองปลายพร้อมกัน**
  เช่น รัฐที่เฝ้าการเชื่อมต่อของคุณและของคู่สนทนาของคุณ หรือตั้ง
  เพื่อนบ้านทั้งสอง สามารถจับคู่เมื่อเวลาผ่านไป: แพ็กเกจออกทางฝั่งคุณ
  ไม่นานหลังจากนั้นแพ็กเกจเข้าที่ฝั่งคู่สนทนาของคุณ
  ทำซ้ำบ่อยพอ ก็ได้ความเชื่อมโยงหนึ่ง
- กระแสพรางทำให้การจับคู่นี้ยากขึ้น แต่ไม่ป้องกันมัน มันปกปิด
  ข้อความรายตัว ไม่ใช่ปริมาณ: ผู้ที่ส่งมากเพิ่ม
  การจราจรรวมของอุปกรณ์ตน
- ผู้ติดต่อที่เป็นเพื่อนบ้านถาวรของคุณรู้ **เมื่อใด** และ **ปริมาณเท่าใด**
  ที่คุณส่งและรับ -- ไม่ใช่กับใครและไม่ใช่อะไร หากอันตราย
  มาจากคนรอบข้างตัวคุณเอง คุณสามารถยกเว้นผู้ติดต่อทุกคนจากมัน (ดู
  บทที่ 3, "ห้ามใช้เป็นเพื่อนบ้านถาวร")
- หากผู้ใช้ใหม่สองคนมีเพื่อนบ้านคนเดียวกันเพียงคนเดียว ข้อความของพวกเขา
  ผ่านโหนดนั้นพอดี และมันเห็นทั้งสองปลาย ทันทีที่ฝ่ายใดฝ่ายหนึ่ง
  มีเพื่อนบ้านเพิ่ม นั่นก็จบลง
- คำเชิญของคุณมีที่อยู่อินเทอร์เน็ตของคุณ ผู้ที่มีบรรทัดข้อความ
  เห็นว่าคุณออนไลน์อยู่ที่ไหน -- ให้มันเฉพาะคนที่คุณไว้วางใจเรื่องนั้น
- เพื่อนบ้านที่ส่งต่อเห็นว่ารหัสสองอันแลกแพ็กเกจกัน --
  ไม่ใช่ใครอยู่เบื้องหลัง และไม่ใช่มีอะไรอยู่ข้างใน
- สัญญาณของสายที่กำลังดำเนินอยู่ อาจ เมื่อเพื่อนบ้านแรก
  ไม่ตอบสนองในขณะนั้น ผ่านโหนดที่เห็นทั้งสองปลาย; มันรู้
  ว่าคุณทั้งสองโทรคุยกัน
- ไฟล์ขนาดใหญ่ที่คุณให้ความยินยอม เครื่องที่ส่งต่อหรือ
  เก็บรักษามันเห็นทั้งสองปลาย (ดูบทที่ 4)
- สำหรับการโทร การป้องกันจากผู้ให้บริการไม่มีผล และผู้ติดต่อ
  ของคุณเห็นที่อยู่อินเทอร์เน็ตของคุณ (ดูบทที่ 7)

### เกิดอะไรขึ้นเมื่อคู่สนทนาของคุณออฟไลน์?

1. Cleona เริ่มเส้นทางที่เหมาะสมทั้งหมดพร้อมกัน: ใน Wi-Fi เดียวกันโดยตรง
   บนอินเทอร์เน็ตผ่านเพื่อนบ้านสองตัว -- และเพิ่มกล่องจดหมาย
2. สำหรับกล่องจดหมาย Cleona ฝากข้อความที่เข้ารหัสที่เพื่อนบ้าน
   สามตัว ทันทีที่สองตัวยืนยันการรับ มันนับเป็น
   ฝากแล้ว
3. Cleona เลือกเพื่อนบ้านสำหรับสิ่งนี้โดยเน้นที่ที่คู่สนทนาของคุณ
   ตรวจด้วย -- ก่อนเพื่อนบ้านที่คำเชิญของเขาระบุ
4. ข้อความรอที่นั่นสูงสุด 7 วัน เมื่อคู่สนทนาของคุณกลับมา
   เขาเอามันและยืนยันการรับกับคุณ ก็ต่อเมื่อนั้นคุณจึงเห็น
   ติ๊กคู่

กล่องจดหมายสามารถเปิดได้เฉพาะคู่สนทนาของคุณ: การเอาไปและลบ
ทำได้เฉพาะด้วยกุญแจที่เฉพาะเขามี และลดหลังเขายืนยันการรับเท่านั้น
เพื่อนบ้านเห็นเฉพาะแพ็กเกจที่เข้ารหัสใต้ค่าที่เปลี่ยนทุกวัน

### คนแปลกหน้าไม่ผ่าน

จากคนที่ไม่ใช่ทั้งผู้ติดต่อของคุณและไม่ใช่สมาชิกของกลุ่มร่วม
Cleona รับเพียงสองสิ่ง:
คำขอกุญแจสาธารณะของคุณ ตราบใดที่คำเชิญของคุณยังเปิดอยู่คำหนึ่ง
และคำขอผู้ติดต่อหนึ่ง คำขอต้องมีคำเชิญ
ที่ถูกต้องจากคุณ และผู้ส่งต้องแก้ภารกิจคำนวณ
ก่อนหน้านั้น ทุกอย่างอื่น -- ข้อความ การโทร
ไฟล์ -- ถูกทิ้งก่อนมันถึงแอป ผู้ที่มีเพียงนามบัตรพิมพ์
ของคุณจึงไม่สามารถโทรหาคุณได้ง่ายๆ สมาชิกของกลุ่มร่วม
ติดต่อคุณได้เฉพาะในกลุ่มนั้น -- ด้วยข้อความกลุ่มและ
สายกลุ่ม ไม่มีทางแบบส่วนตัว

### ต้านการเซ็นเซอร์

Cleona ถูกสร้างให้บล็อกได้ยาก:

- **ไม่มีเซิร์ฟเวอร์ ไม่มีที่อยู่ถาวร.** ในแอปไม่มีที่อยู่ที่
  ใครจะบล็อกได้ และเครือข่ายไม่พึ่งพาโหนดใดโหนดเดียว
- **ไม่มีพอร์ตถาวร.** ทุกอุปกรณ์เลือกพอร์ตสุ่มเมื่อเริ่มต้นครั้งแรก
  ไม่มีหมายเลขพอร์ตที่รู้จักซึ่งใครจะรู้จัก
  การจราจร Cleona ได้
- **เหมือนข้อมูลสุ่ม.** การสร้างการเชื่อมต่อระหว่างอุปกรณ์สองเครื่องถูก
  เข้ารหัสให้แยกจากข้อมูลสุ่มไม่ได้
- **จุดเข้ามากมาย.** คำเชิญทุกคำ เพื่อนบ้านทุกตัว และอุปกรณ์ทุกเครื่องใน
  Wi-Fi เดียวกันคือเส้นทางกลับเข้าเครือข่ายที่เป็นไปได้

### การเก็บกุญแจอย่างปลอดภัย

บนแพลตฟอร์มที่รองรับ Cleona เก็บกุญแจเข้ารหัส
ของคุณในพวงกุญแจปลอดภัยของระบบปฏิบัติการ (Android Keystore,
iOS Keychain, macOS Keychain) ที่มีให้ นั่นให้การปกป้อง
สนับสนุนด้วยฮาร์ดแวร์สำหรับกุญแจของคุณ

### การเข้ารหัสฐานข้อมูล

ข้อความและบทสนทนาของคุณอยู่ในฐานข้อมูลที่เข้ารหัส -- แยก
สำหรับตัวตนแต่ละตัว แต่ละตัวมีกุญแจของตัวเอง เข้ารหัส
ไม่ใช่แค่ฐานข้อมูลเอง แต่รวมถึงไฟล์ชั่วคราวของมัน; ไม่มีอะไรถูก
เขียนลงดิสก์โดยไม่เข้ารหัส แม้ชั่วขณะ การตั้งค่า ผู้ติดต่อ และสื่อก็
ถูกเก็บเข้ารหัสด้วย

กุญแจถูกได้มาจาก 24 คำของคุณและมีอยู่เฉพาะ
บนอุปกรณ์ของคุณ แม้ผู้ที่เอาอุปกรณ์ของคุณไปและอ่าน
ข้อมูลออก ก็พบเฉพาะข้อมูลที่อ่านไม่ได้โดยไม่มีกุญแจเหล่านี้

ไม่เข้ารหัสเฉพาะที่คุณเอาเนื้อหาออกจาก Cleona ด้วยตัวเอง:
- เมื่อคุณบันทึกไฟล์จากแชทไปยังอุปกรณ์ของคุณ
- เมื่อคุณใช้ปุ่มภาพหน้าจอใส่ภาพลงในรูปภาพของคุณ
- เมื่อคุณแชร์บางอย่างไปยังแอปอื่น
- เมื่อคุณตั้งค่าการเก็บสื่อถาวร (บทที่ 13): ต้นฉบับที่เก็บถาวร
  อยู่ไม่เข้ารหัสบนที่เก็บเครือข่ายที่บ้านของคุณ
  เพื่อให้คุณเปิดมันที่นั่นได้โดยไม่ต้องใช้ Cleona
- เมื่อคุณสะท้อนนัดหมายไปยังปฏิทินระบบ Android: ที่นั่น
  แอปอื่นที่มีสิทธิ์เข้าถึงปฏิทินสามารถอ่านมันได้

สิ่งที่ออกไปแบบนี้แล้วจะไม่ถูกลบพร้อมข้อความและไม่หมดอายุ
พร้อมข้อความ

### การปกป้องบนหน้าจอ

บน Android, Windows และ macOS Cleona ไม่อนุญาตให้แอปอื่น
บันทึกหน้าจอ หากคุณต้องการภาพ ใช้ปุ่มภาพหน้าจอในแถบบน:
มันใส่ภาพลงในรูปภาพของคุณ -- โดยไม่เข้ารหัส ในบทสนทนา
ที่ไม่อนุญาตให้ส่งต่อ จะไม่มีภาพหน้าจอ

## 15. อัปเดตซอฟต์แวร์

### ฉันได้รับอัปเดตอย่างไร?

Cleona สามารถอัปเดตผ่านเส้นทางต่างๆ เป้าหมายคือให้คุณ
ได้รับอัปเดตได้แม้เมื่อช่องทางจำหน่ายรายหนึ่งล้มเหลว
หรือถูกบล็อก:

1. **App Store / Play Store:** เมื่อ Cleona ปรากฏที่นั่นและคุณติดตั้ง
   Cleona ผ่าน Store คุณได้รับอัปเดตผ่าน Store ตามปกติ
   บน iPhone อัปเดตมาผ่าน TestFlight
2. **GitHub Releases:** บนหน้า GitHub ของโครงการคุณพบ
   แพ็กเกจติดตั้งที่ลงลายมือชื่อสำหรับทุกแพลตฟอร์ม
3. **อัปเดตผ่านเครือข่าย:** Cleona สามารถดึงอัปเดตโดยตรงผ่านเครือข่าย
   -- โดยไม่ต้องมีเซิร์ฟเวอร์ดาวน์โหลด เวอร์ชันใหม่ถูก
   แบ่งเป็นชิ้นที่แก้ความผิดพลาดที่กระจายในเครือข่าย; ส่วนหนึ่ง
   เดินทางไปกับกระแสพรางด้วยซ้ำ อุปกรณ์ของคุณรวบรวมชิ้น
   เพียงพอและประกอบอัปเดต ที่ถ่ายโอนส่วนใหญ่เป็นเพียงส่วน
   ที่เปลี่ยนแปลง -- ไม่กี่ MB แทนทั้งแอป ข้อนี้ใช้กับ Linux,
   Windows และ Android; บน macOS คุณโหลดเวอร์ชันใหม่จาก
   เว็บไซต์หรือจาก GitHub
4. **ลิงก์คำเชิญ:** คุณสามารถสร้างลิงก์คำเชิญที่บรรจุ
   ทุกสิ่งที่ผู้ใช้ใหม่ต้องการเพื่อติดตั้ง Cleonaและเชื่อมต่อ
   กับเครือข่าย
5. **ถ่ายโอนทางกายภาพ:** ในสภาพแวดล้อมไม่มีอินเทอร์เน็ตคุณสามารถ
   ส่งต่อ Cleona ให้ผู้อื่นผ่าน USB stick หรือในเครือข่ายท้องถิ่น

### อัปเดตทำงานอย่างไร

1. Cleona รวบรวมชิ้นของอัปเดตใหม่โดยอัตโนมัติใน
   เบื้องหลังและประกอบมัน
2. ก็ต่อเมื่ออัปเดต **สมบูรณ์** และ **ลายมือชื่อถูกตรวจสอบ**
   แล้ว Cleona จึงเสนอมันให้คุณ คุณจึงไม่ได้รับการเสนอ
   อัปเดตครึ่งๆ กลางๆ หรือไม่ตรวจสอบ
3. เมื่อคุณแตะ "ติดตั้ง" การติดตั้งเริ่มโดยไม่ถาม
   อีก บน Android ระบบแสดง
   กล่องโต้ตอบการติดตั้งเพิ่มเติม

เวอร์ชันเก่ากว่าไม่ถูกเสนอ -- อัปเดตไปข้างหน้าเท่านั้นเสมอ หาก
เวอร์ชันหนึ่งเก่าจนไม่สามารถทำงานร่วมกับเครือข่ายได้อีก
Cleona ระบุสิ่งนั้นชัดเจนและขอให้คุณ
อัปเดต

### การตรวจสอบลายมือชื่อ

ทุกอัปเดตถูกลงลายมือชื่อสองครั้ง: ด้วยวิธีคลาสสิกและวิธี

## 16. คำถามที่พบบ่อย

### "ฉันใช้ Cleona โดยไม่มีอินเทอร์เน็ตได้ไหม?"

Cleona ต้องการการเชื่อมต่อเครือข่าย แต่ไม่จำเป็นต้องเป็นอินเทอร์เน็ต:
ใน Wi-Fi เดียวกัน อุปกรณ์ Cleona หากันเองและสามารถเขียนหากันได้
โดยไม่มีการเข้าถึงอินเทอร์เน็ตเลย คุณไม่ต้องออนไลน์
พร้อมกันกับคู่สนทนาของคุณ: หากเขาออฟไลน์ ข้อความรอ
สูงสุด 7 วันในกล่องจดหมายที่เพื่อนบ้านสามตัว จนกว่าเขาจะเอาไป

### "ถ้าฉันทำวลีรหัสฟื้นหายล่ะ?"

ตราบใดที่อุปกรณ์หนึ่งที่มีตัวตนของคุณยังทำงานอยู่ ไม่มีอะไรหายไป --
คุณเขียนต่อที่นั่นได้เลย บนอุปกรณ์ที่คุณสร้างตัวตน คุณสามารถ
อ่าน 24 คำอีกครั้งได้ในกรณีส่วนใหญ่ (ดูบทที่ 2) อย่าไว้ใจสิ่งนี้:
การติดตั้งใหม่ล้างสำเนานี้ทิ้ง และบน Android การลบหรือเปลี่ยน
การล็อกหน้าจอก็ทำลายมันเช่นกัน หากคุณไม่มีทั้งคำและ
อุปกรณ์ ก็ไม่มีทางกลับ -- ไม่ใช่ผ่านผู้ติดต่อของคุณ
นักพัฒนา หรือใครก็ตาม นั่นคือเหตุที่สำคัญมากที่จะเก็บ
24 คำให้ปลอดภัย

### "มีใครอ่านข้อความของฉันระหว่างทางได้ไหม?"

ไม่ ข้อความทุกรายการถูกเข้ารหัสด้วยกุญแจใช้ครั้งเดียวที่ใช้
กับข้อความนั้นเท่านั้น เฉพาะคุณและคู่สนทนาของคุณเท่านั้นที่สามารถ
ถอดรหัสข้อความ ไม่มีเซิร์ฟเวอร์กลาง ไม่มีกุญแจหลัก และไม่มี
การเข้าถึงสำหรับนักพัฒนา แม้แต่อุปกรณ์ที่ส่งต่อข้อความ
ระหว่างเส้นทางขนส่ง มันเห็นเฉพาะข้อมูลเข้ารหัสที่เป็นก้อน
และรหัส เพื่อนบ้านของคุณรู้ว่าแพ็กเกจมาจากคุณ แต่ไม่รู้ว่า
มันไปถึงใคร; เพื่อนบ้านของคู่สนทนาของคุณรู้ว่ามันไปถึงใคร
แต่ไม่รู้ว่ามาจากใคร

### "ทำไมฉันไม่ต้องมีหมายเลขโทรศัพท์?"

เพราะตัวตนของคุณเป็นทางการเข้ารหัสล้วน แทนหมายเลข
โทรศัพท์หรือที่อยู่อีเมลที่เชื่อมโยงกับชื่อจริงของคุณ คู่กุญแจ
ที่ถูกสร้างบนอุปกรณ์ของคุณระบุตัวคุณ คุณเพิ่มผู้ติดต่อผ่าน
QR code, NFC หรือบรรทัดข้อความของคำเชิญของคุณ -- ไม่ใช่ผ่าน
สมุดโทรศัพท์ นั่นหมายถึง
ความเป็นส่วนตัวที่มากขึ้น เพราะบัญชีแอปส่งข้อความของคุณไม่ได้ผูก
กับตัวตนจริงของคุณ

### "ฉันหาคนบน Cleona ได้อย่างไร?"

Cleona ไม่มีการค้นหาผู้ติดต่อตามหมายเลขโทรศัพท์หรือชื่อโดยตั้งใจ --
นั่นจะเป็นปัญหาความเป็นส่วนตัว แทนที่ คุณแลกคำเชิญโดยตรง: ผ่าน
QR code, NFC หรือเป็นบรรทัดข้อความผ่านทางอื่น นั่นเหมือน
การแลกนามบัตรแทนการค้นในสมุดโทรศัพท์

### "Cleona ใช้ในต่างประเทศได้ไหม?"

ได้ ตราบใดที่คุณมีการเชื่อมต่ออินเทอร์เน็ต Cleona ทำงาน
ได้ทุกที่ในโลก เนื่องจากไม่มีเซิร์ฟเวอร์กลางและไม่มีที่อยู่ถาวร
บริการจึงไม่สามารถถูกปิดสำหรับประเทศใดประเทศหนึ่งได้ง่ายๆ วิธีที่ Cleona
ทำให้การบล็อกยากขึ้นอยู่ในบท "ความปลอดภัย" ภายใต้ "ต้านการเซ็นเซอร์" อย่างไรก็ตาม ประเทศที่
บล็อกการจราจรที่ไม่รู้จักทุกอย่างที่พรมแดนก็สามารถ
หยุด Cleona ได้

### "Cleona ฟรีไหม?"

ใช่ Cleona ใช้งานได้ฟรีและไม่มีโฆษณา เนื่องจากไม่มี
เซิร์ฟเวอร์กลาง จึงไม่มีค่าเซิร์ฟเวอร์เกิดขึ้นสำหรับการดำเนินงาน ใน
การตั้งค่าภายใต้ "สนับสนุน Cleona" -> "บริจาค" คุณสามารถ
สนับสนุนการพัฒนาโดยสมัครใจ

### "ข้อความของฉันมีติ๊กเดียว -- หมายความว่าอย่างไร?"

ข้อความกำลังเดินทาง แต่คู่สนทนาของคุณยังไม่ยืนยัน
การรับ -- ส่วนใหญ่เพราะเขากำลังออฟไลน์อยู่ นั่นไม่ใช่ข้อผิดพลาด:
ข้อความรอสูงสุด 7 วันในกล่องจดหมาย ทันทีที่เขาเอาไป คุณเห็น
ติ๊กคู่ นาฬิกาหมายถึงยังไม่มีเส้นทางใดพาข้อความไป -- มัน
ออกเดินทางเองทันทีที่มีเส้นทาง; เครื่องหมายเตือน
หมายถึงมันหาเส้นทางไม่ได้ตลอด 14 วันและคุณสามารถ
ส่งใหม่ได้

### "ทำไมข้อความถึงมาถึง iPhone ของฉันช้า?"

iOS ไม่อนุญาตให้แอปทำงานในเบื้องหลังได้ตลอดเวลา Cleona
จะถูกปลุกเป็นครั้งคราวเพียงชั่วขณะ ว่าจะปลุกเมื่อไรนั้น iOS
เป็นผู้กำหนด จากนั้นจะรับทุกอย่างมา ทันทีที่คุณเปิดแอป Cleona
จะรับสิ่งที่เก็บไว้ให้คุณ

### "ฉันย้ายจาก WhatsApp มา Cleona ได้ไหม?"

ได้ แต่คุณไม่สามารถถ่ายโอนแชท WhatsApp ของคุณ Cleona และ WhatsApp
เป็นระบบที่แตกต่างกันพื้นฐาน คุณต้องเพิ่มผู้ติดต่อ
ทีละคนใน Cleona ง่ายที่สุดคือส่งบรรทัดข้อความของ
คำเชิญของคุณให้ผู้ติดต่อของคุณ คำขอทุกคำที่มาถึงเช่นนั้นคุณยืนยัน
ด้วยตัวเองใต้ "คำขอ"

### "ฉันใช้ Cleona บนหลายอุปกรณ์พร้อมกันได้ไหม?"

ยังไม่ได้ อุปกรณ์ที่สองสำหรับตัวตนเดียวกันจะมากับ
เวอร์ชันถัดไป (บทที่ 11) บนหลายอุปกรณ์ วันนี้คุณสามารถใช้
ตัวตนต่างกันได้

### "ฉันได้รับอัปเดตอย่างไรเมื่อ App Store ถูกบล็อก?"

Cleona สามารถดึงอัปเดตโดยตรงผ่านเครือข่าย โดยไม่พึ่งพา
App Store เว็บไซต์ หรือเซิร์ฟเวอร์ดาวน์โหลด หากอุปกรณ์อื่นใน
เครือข่ายมีเวอร์ชันล่าสุด อุปกรณ์ของคุณสามารถโหลด
อัปเดตจากที่นั่น ความถูกต้องถูกตรวจสอบด้วยลายมือชื่อดิจิทัลของ
นักพัฒนา อีกทางเลือก ผู้ติดต่อสามารถส่งต่อแอปให้คุณผ่าน
ลิงก์คำเชิญหรือ USB stick เพิ่มเติมในบท
"อัปเดตซอฟต์แวร์"
